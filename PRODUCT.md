# Product

## Register

product

## Users

Two overlapping audiences using the same tool differently:

- **Power viewers**: Watch many streams daily across Twitch and Kick. They want efficiency, low resource use compared to browser tabs, and fast switching between content. Keyboard shortcuts, multistream layouts, and quick-access follows matter.
- **Casual multi-platform viewers**: Have favorite streamers on both platforms. They want one app to find everyone without switching sites. Discoverability, a simple browsing flow, and frictionless playback matter.

Both audiences are desktop-first and value performance. They came here to watch streams, not to admire the UI.

## Product Purpose

StreamFusion unifies Twitch and Kick into a single, lightweight desktop app. It replaces the multi-tab browser workflow with a purpose-built tool that plays streams, surfaces chat, and organizes followed content across platforms. Success looks like: users stop opening Twitch and Kick in their browser.

## Brand Personality

**Confident, clean, sharp.**

StreamFusion speaks through precision, not decoration. The interface is quiet until you need it, then it responds instantly. No flourishes that don't earn their place. Think Linear's restraint applied to a media-focused tool: every element is deliberate, every interaction is fast, every screen is uncluttered.

## Anti-references

- **Twitch/Kick clones**: StreamFusion is its own product with its own identity. It should never look like a reskinned version of either platform.
- **Gamer aesthetic**: No neon gradients, RGB glow, angular shapes, or esports styling. The audience watches games; the tool itself is not a game.
- **Generic SaaS**: No bland dashboards, gray-on-white corporate energy, or cookie-cutter admin panels. This is a media app, not a B2B tool.
- **Electron jank**: Must feel native and tight. No visible web-page-in-a-window artifacts, no sluggish transitions, no layout shifts. If it feels like a browser tab with a title bar, it's failed.

## Design Principles

1. **Content is the product.** The stream is why users are here. UI frames the content; it never competes with it. When in doubt, show less chrome.
2. **Earned precision.** Every pixel, every interaction, every animation earns its place. Nothing decorative without function. The craft is in what's removed, not what's added.
3. **Desktop-native conviction.** Feel like a real application, not a web page. Respond at native speed. Respect platform conventions. Own the window.
4. **Progressive power.** Casual users see simplicity. Power users discover depth. Features reveal themselves through use, not through cluttered first impressions.
5. **Platform-agnostic identity.** StreamFusion has its own visual language. Platform colors (Twitch purple, Kick green) are accents within that language, not the identity itself.

## Accessibility & Inclusion

- WCAG AA compliance as baseline: 4.5:1 contrast for normal text, 3:1 for large text and UI components.
- Full keyboard navigation for all interactive elements.
- Screen reader support with proper ARIA labels and roles.
- Respect `prefers-reduced-motion` for all animations.
