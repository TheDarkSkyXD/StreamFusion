## Live integration findings

The actual 7TV v4 GraphQL endpoint rejected the initial batch sizes with `Query is too complex`. The adapter now requests five users per query. A replay through the production adapter loaded 240 public chat users with zero provider failures and found cosmetics for 20 users. The batch-limit and adapter replay logs are retained with the local evidence.

Guest verification also fixed four reproduced bugs:

- Kick Guest Follows now read public live, channel, and video data before using relay fallback. Native captures 42 and 43 show a saved Spreen follow and its real live viewer count.
- Search hydrates real stream records instead of inventing a zero-viewer stream. Its live cards now open Watch. Captures 57b, 58, and 59 show xQc's 24.5K viewers and the resulting live Watch screen.
- Settings search matches visible category labels and descriptions. Playback quality normalizes the legacy `2k` value and presents one 1440p option. Capture 73 verifies the dropdown and capture 74 restores Auto.
- Navigation stores channel identity fields without presentation-only avatar data. A failing Search-to-Watch serialization test passes after the fix. Capture 71 confirms a cold restart restores xQc Watch without the damaged-navigation banner.

## Official badge follow-up

Mobile previously used only Twitch global badge artwork and discarded Kick identity badges. Channel-specific Twitch subscriber and Bits artwork now overrides matching global versions. Kick retains broadcaster, moderator, VIP, verified, subscriber, gift, and other supported role artwork in live messages, recent history, and recorded replay. Kick channel subscriber badges use the highest tier at or below the user's actual month count. Gift badges use the desktop count-based colors.

Both channel readers bound their caches and network requests. Late artwork updates existing messages, paused reading rows, picker rows, and selected messages without moving the reading position. A channel switch fences old responses. Kick now reports a connection only after its matching subscription acknowledgement and handles channel-less protocol errors. This follows the [Pusher wire protocol](https://pusher.com/docs/channels/library_auth_reference/pusher-websockets-protocol/).

The actual Twitch channel adapter returned 88 xQc badge variants, including 75 subscriber and 12 Bits variants. Android capture 78 shows custom subscriber icons alongside provider badges. The actual Kick public channel payload returned ten Spreen subscriber tiers. Spreen had gone offline during the follow-up, so native verification used the live kaneljoseph channel. Captures 79 and 80b show custom subscriber artwork and native SVG gift badges. Capture 81 retains the same four paused message IDs as 80b while the live stream continues. The emulator was closed after verification.

Anonymous Twitch badge reads reuse desktop's web GraphQL compatibility path. Twitch's [documented channel badge API](https://dev.twitch.tv/docs/api/reference/#get-channel-chat-badges) requires an access token; this guest implementation does not claim to use that authenticated API. Deterministic tests cover exact-version fallback, cache expiry, stale results, recorded hydration, paused updates, subscription failures, and deletion actor aliases. Rare live events and authenticated actions retain the limits described above.
