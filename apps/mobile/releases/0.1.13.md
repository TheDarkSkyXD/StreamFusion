# StreamFusion Android 0.1.13

This release includes all 15 commits since Android 0.1.12.

## Changes

- Keep the display awake while a stream plays, buffers, or recovers, including fullscreen, the floating mini player, and system Picture-in-Picture.
- Automatically renew failed Kick and Twitch live sources and retry temporary playback failures. Recovery keeps the same player and continues in Picture-in-Picture without requiring a Retry tap.
- Restore Kick chat connections and reconnect Kick and Twitch chat automatically after interruptions.
- Keep Search, Following, Watch, Activity, and More in one row after returning from fullscreen or Picture-in-Picture. Use consistent tab styling across screens.
- Restore follower counts on channel profiles and channel avatars on recorded media. Simplify offline profiles and keep recent broadcasts accessible.
- Load and play Kick clips, and restore Twitch video thumbnails.
- Simplify update checks and prompts. Keep update controls in Settings and remove repeated update notices from other screens.

## Install or update

On Android 11 or newer, download `StreamFusion-android-v0.1.13.apk` and open it. Approve Android's installation prompt. Keep StreamFusion installed to preserve your data.

Existing users can check for this release in Settings > Updates. This release uses Android version code 16 and the existing production signing certificate.

## Verify the download

```bash
sha256sum --check SHA256SUMS
```

## Verification

Playback recovery was exercised with real Kick and Twitch streams in the Android emulator, including forced HTTP failures, network outages, fullscreen, the floating mini player, and system Picture-in-Picture. Screen-timeout checks confirmed that active recovery stays awake. Physical-device testing was not performed for these playback fixes.
