# StreamFusion Android 0.1.15

This release includes every commit since Android 0.1.14.

## Changes

- Selecting Highest quality now chooses the stream's highest available resolution instead of Auto.
- Player Options now opens as a full-screen page with scrolling sections, a left back chevron, and radio buttons beside the selected quality. Keep refresh and fullscreen controls on the player.
- Center the play and pause buttons and match Twitch's icon sizes. Show a dark backdrop behind the controls, viewer count, and stream uptime when controls are visible, including fullscreen. The back button hides with the other controls.
- Move the Options gear to the top right and bring secondary player tools into Options. Remove the mobile volume slider while keeping the mute button.
- Show channel avatars with live rings above chat. Twitch partners and verified Kick channels show their provider badge beside the name; other channels show their platform logo.
- Restore Kick channel profile backgrounds.
- Request Android notification permission when enabling background stream alerts.

## Install or update

On Android 11 or newer, download `StreamFusion-android-v0.1.15.apk` and open it. Approve Android's installation prompt. Keep StreamFusion installed to preserve your data.

Existing users can check for this release in Settings > Updates. This release uses Android version code 18 and the existing production signing certificate.

## Verify the download

```bash
sha256sum --check SHA256SUMS
```

## Verification

Player controls, quality selection, Options navigation and scrolling, channel avatars and badges, and Kick profile backgrounds were exercised in the Android emulator during development. Physical-device testing was not performed for these changes.
