# StreamFusion Android 0.1.8

This stable release includes every committed change since Android 0.1.7.

## Changes

- Added Twitch device-code sign-in and Kick browser sign-in, including callback recovery when the app returns from the background.
- Tapping the player expands stream information while chat stays underneath. The card includes channel details, tags, Following, and a notification bell that saves per-channel live alerts.
- Restored Watch language filtering, removed the carousel, added loading feedback, and made catalog requests retry automatically.
- Restored category browsing and pagination, with coverage for anonymous category clips and videos.
- Restored portrait orientation after fullscreen playback and Picture-in-Picture navigation.
- Removed provider-page shortcuts from mobile and desktop.
- Updated Android upgrade verification and project branding.

## Install or update

On Android 11 or newer, download `StreamFusion-android-v0.1.8.apk` and open it. Approve Android's installation prompt. Keep StreamFusion installed to preserve your data.

Existing users can open Settings > Updates > Check now, accept the update, and approve installation in Android. The APK uses the existing production signing certificate and Android version code 11.

## Verify the download

```bash
sha256sum --check SHA256SUMS
```
