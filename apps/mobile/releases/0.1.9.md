# StreamFusion Android 0.1.9

This stable release includes every committed change since Android 0.1.8.

## Changes

- Twitch and Kick sign-in now open inside StreamFusion. Closing the sign-in page returns to the app and preserves the pending connection. Twitch approval finishes after closing the page; Kick returns through Open StreamFusion.
- Live playback recovers when it falls behind the current live window.
- Temporary playback network failures retry automatically.
- Category browsing uses a virtualized list for continued scrolling and pagination.

## Install or update

On Android 11 or newer, download `StreamFusion-android-v0.1.9.apk` and open it. Approve Android's installation prompt. Keep StreamFusion installed to preserve your data.

Existing users can open Settings > Updates > Check now, accept the update, and approve installation in Android. The APK uses the existing production signing certificate and Android version code 12.

## Verify the download

```bash
sha256sum --check SHA256SUMS
```

## Verification limits

The real Twitch and Kick sign-in pages, return and cancellation flows, and opening sign-in during live playback were checked on Android. Complete real-account consent and token exchange remain unverified.
