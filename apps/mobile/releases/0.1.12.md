# StreamFusion Android 0.1.12

This release includes the Android changes committed since 0.1.11.

## Changes

- Restore Twitch sign-in when release configuration leaves the public client ID blank.
- Search shows broader Twitch and Kick channel matches. All includes the available channel results, and search pages load more results where the provider supports continuation.
- Category stream lists continue through Twitch and Kick pages independently. Failed pages keep earlier streams and can be retried. Changing filters resets the list position and hides errors from excluded providers.
- Remove the bottom category search field, including "Search in IRL."
- Show Twitch verified badges for Partners. Affiliates no longer receive an incorrect verified badge.
- Keep chat at the newest messages until you scroll away, with a control to return to live chat. Message text wraps inline after the username.
- Open chat user sheets with message history, profile details, copy actions, Mention, and Reply. Sheets preserve username colors and 7TV paints, support swipe dismissal, and show moderation controls only for verified channel roles.
- MultiView closes its Add stream form only after adding a new player. Duplicate attempts keep the form open, and dismissing it clears its validation messages.

## Install or update

On Android 11 or newer, download `StreamFusion-android-v0.1.12.apk` and open it. Approve Android's installation prompt. Keep StreamFusion installed to preserve your data.

Existing users can open Settings > Updates > Check now, accept the update, and approve installation in Android. This release uses Android version code 15.

## Verify the download

```bash
sha256sum --check SHA256SUMS
```

## Verification limits

Discovery was checked in the Android emulator while signed out, including exact and partial names, provider filters, and category streams beyond the first page. Kick's public search limits the offline matches it returns. A live comparison with desktop remains deferred. Complete real-account sign-in consent and token exchange remain unverified.
