# StreamFusion Android 0.1.11

This release includes the Android changes committed since 0.1.9. Version 0.1.10 was not published because its build failed.

## Changes

- Choose small or large live stream cards in Settings > General > Show large stream cards. The choice applies to Watch, Following, search results, channels, and categories.
- Live thumbnails refresh every five minutes while the app is open and when you return to it. Duplicate Twitch streams no longer appear in the Watch list.
- Search opens with a category grid. Focused search has separate All, Channels, Streams, and Categories tabs, each with its own history. Returning from a result preserves your search.
- Send recent and global emotes from the quick emote row without changing your message draft or reply.
- Twitch and Kick sign-in open in resizable sheets above the app.
- Android checks eligible followed channels for live alerts in the background, without requiring Firebase. Checks run about every 15 minutes, though Android may delay them to save battery. Force-stopping the app pauses checks until you reopen it.
- The Android app now uses React Native libraries directly in place of Expo, while retaining the existing production app identity and signing certificate.

## Install or update

On Android 11 or newer, download `StreamFusion-android-v0.1.11.apk` and open it. Approve Android's installation prompt. Keep StreamFusion installed to preserve your data.

Existing users can open Settings > Updates > Check now, accept the update, and approve installation in Android. This release uses Android version code 14.

## Verify the download


## Verification limits

Both stream card sizes were checked on all five mobile screen types, including saved settings after restart and thumbnail updates on return to the app. Complete real-account sign-in consent and token exchange remain unverified.
