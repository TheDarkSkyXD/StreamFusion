After the link is copied, what should change?

All options use the existing neutral Share button. These examples show the success state.

A · RECOMMENDED

Toast only

The button stays stable while a short confirmation appears. Clear, accessible, and consistent with StreamFusion’s existing clipboard actions.

✓ Link copied
B

Button changes + toast

The button temporarily becomes “Copied” and a toast appears. Strong confirmation, but duplicates the same message and changes the action row width.

✓ Link copied
C

Button changes only

The button temporarily becomes “Copied.” Compact, but feedback may be missed if focus or attention moves immediately after clicking.

Clipboard failures will be grilled separately after the success state is chosen.
