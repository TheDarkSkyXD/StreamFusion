Multi Streams Layout Strategy

Question: what should "multiple layouts" mean for a page that auto-adjusts from 1 to 6 StreamSlots?

Recommended

A. Auto Grid plus Focus

The page chooses the best grid for the active StreamSlot count. The user switches between Grid and Focus, not every row/column variant.

GridFocusAuto by count
1 slot1x1
2 slots2 across
3-4 slots2x2
5-6 slots3x2

Best fit: simple, stable, close to the current implementation, and good for drag-to-reorder.

More Control

B. Preset Chooser per Count

The user can pick variants like 2x1 vs 1x2, 3x2 vs 2x3, and main-plus-side layouts. The app still adapts when count changes.

GridSideFocus
3 slotsMain + 2
4 slots2x2
6 slots3x2 or 2x3

Tradeoff: stronger control, but more toolbar complexity and more state migration.

Advanced

C. Saved Custom Layouts

The user saves named arrangements. Opening a saved layout can restore streams, order, layout mode, and chat target.

Preset: Mod NightSaveManage
Saved layoutFocus rail
Saved layoutSix slot grid

Tradeoff: powerful, but probably a separate feature because it touches persistence, editing, and failure states.
